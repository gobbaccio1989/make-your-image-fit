How to compress an image to 100KB

If a website requires an image to be 100KB or smaller, you can use this free image compressor to reduce the file size directly in your browser.

  1. Choose or drag your image into the tool.
  2. Select the output format you want.
  3. Choose your preferred sizing option if necessary.
  4. Click Compress to 100KB.
  5. Download the compressed image.

For JPEG and WebP images, the tool automatically adjusts image quality to try to reach the 100KB target while preserving as much quality as possible.

Why compress an image to 100KB?

Some websites, online forms and applications impose strict file-size limits. A photo that looks perfectly normal can still be too large to upload because modern cameras and phones create high-resolution images.

Compressing an image to 100KB can make it easier to upload, share and use on websites with strict file-size requirements.

Does the image have to be exactly 100KB?

Usually, when a website says an image must be “100KB or less”, the important requirement is that the final file does not exceed 100KB.

This tool therefore aims for a file size at or below 100KB rather than trying to produce exactly 100.00KB.

Can I compress JPG, PNG and WebP images?

Yes. You can upload JPG, PNG and WebP images and choose the output format. JPEG and WebP are generally more suitable when the goal is to reduce a photographic image to a small file size.

PNG files can sometimes remain relatively large because PNG uses lossless compression. If a PNG cannot be reduced below 100KB at the selected dimensions, the tool will tell you.

Is this image compressor free?

Yes. Make Your Image Fit is free to use for image resizing, compression and conversion.

Are my images uploaded?

No. Image processing is performed directly in your browser using your device. Your image does not need to be uploaded to a server for compression.
