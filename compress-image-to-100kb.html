How to compress an image to 100KB

If a website requires an image to be 100KB or smaller, you can use this free image compressor to reduce the file size directly in your browser.

  1. Choose your image or drag it into the upload area.
  2. Select the output format.
  3. Choose optional image dimensions if needed.
  4. Click Compress to 100KB.
  5. Download the compressed image.

For JPEG and WebP images, the tool automatically adjusts image quality to try to reach the 100KB limit.

Why compress an image to 100KB?

Some websites, forms and online services limit the maximum file size that can be uploaded. A high-resolution photo can easily exceed those limits.

Compressing an image to 100KB can make it easier to upload and share when a website has a strict file-size requirement.

Does the image need to be exactly 100KB?

Usually, when a website says that an image must be “100KB or less”, the important requirement is that the final file does not exceed 100KB.

This tool therefore aims for a file size of 100KB or less rather than trying to create an exactly 100.00KB file.

Can I compress JPG, PNG and WebP images?

Yes. You can choose JPG, PNG or WebP as the output format.

JPEG and WebP are generally more effective for reducing photographic images to a small file size. PNG uses lossless compression and may not be able to reach 100KB without reducing the image dimensions.
